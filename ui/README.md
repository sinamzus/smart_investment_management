# UI — SIM Index Lab

صفحهٔ واقعی (نه نمایشی): همهٔ اعداد از دادهٔ مخزن می‌آیند.

## باز کردن
1. (فقط وقتی داده عوض شد) بسازید:
   ```
   pip install pandas numpy
   python tools/build_ui_data.py
   ```
   خروجی `ui/data/data.js` در مخزن commit شده است؛ پس برای دیدن وضعیت فعلی لازم نیست دوباره بسازید.
2. فایل `ui/index.html` را در مرورگر باز کنید (دوبار کلیک یا `start ui\index.html`). سرور لازم نیست.

## کنترل‌ها
- دکمه‌های «كل / هم‌وزن» و «از ۲۰۱۴ / از ۲۰۱۶»، یا فرمان‌ها در نوار بالا (`/` یا `Ctrl+K`): `IDX K` · `IDX EW` · `WIN 2014` · `WIN 2016` · `THEME` · `HELP`
- نشانگر موس روی نمودار: مقادیر همان روز.
- دکمهٔ CSV هر پنل: خروجی همان جدول.

## چه چیزی واقعی است
نمودار و آمار: بازسازی ما در برابر سری رسمی TSETMC. «روزهای بیشترین انحراف»: تاریخ‌های واقعی با نمادهای مشارکت‌کننده. «ترکیب فعلی»: وزن‌های امروز از قیمت × تعداد سهام. بخش‌های Factor Lab / Rebalance / Reports / Data QA هنوز ساخته نشده‌اند و غیرفعال‌اند.
