# UI — SIM Index Lab

صفحهٔ واقعی (نه نمایشی): همهٔ اعداد از دادهٔ مخزن می‌آیند.

## باز کردن
1. (فقط وقتی داده عوض شد) بسازید:
   ```
   pip install pandas numpy
   python tools/build_ui_data.py
   ```
   خروجی `ui/data/data.js` در مخزن commit شده است؛ پس برای دیدن وضعیت فعلی لازم نیست دوباره بسازید.
2. فایل `ui/index.html` را در مرورگر باز کنید (دوبار کلیک یا `start ui\index.html`). سرور لازم نیست.

## نماها (کلید ۱ تا ۹ یا `GO <نما>` در نوار فرمان)
| نما | محتوا | منبع داده |
|-----|-------|-----------|
| **Index Lab** (۱) | بازسازی «شاخص كل» و «كل (هم وزن)» در برابر رسمی؛ آمار ردیابی؛ روزهای بیشترین انحراف؛ ترکیب فعلی | `data/data.js` |
| **Dividend Lab** (۲) | ماکت سرمایه‌پذیر با تأخیر پرداخت سود: لغزندهٔ تأخیر و نرخ وام (شبیه‌سازی زنده در مرورگر از ۴ سری رسمی)، سناریوهای ثابت، فصلی‌بودن سود، وضعیت داده تاریخ پرداخت | `data/extra.js` |
| **Factor Lab** (۳) | مومنتوم ۱۲−۱ و کم‌نوسان ۲۵۲ روزه (پیش‌نمایش پژوهشی؛ بدون هزینه؛ بدون آزمون معناداری)؛ کیفیت: هنوز ساخته نشده | `data/extra.js` |
| **Rebalance** (۴) | سیاست‌های ریبالانس هم‌وزن: TE در برابر گردش و هزینهٔ فرضی (ورودی قابل‌تنظیم)؛ دوازده ریبالانس اخیر؛ گردش ارزش‌وزن | `data/extra.js` |
| **Data QA** (۵) | جدول ۴۱ صنعت در برابر شاخص صنعت رسمی؛ خطاهای مقیاس/تیغه در سری‌های رسمی؛ جهان داده؛ شکاف‌های شناخته‌شده | `data/extra.js` |
| **Reports** (۶) | خلاصهٔ نتایج، تاریخچهٔ تغییرات روش‌شناسی (از `docs/CHANGELOG.md`)، فصل‌های سند، ابزارها؛ دکمهٔ چاپ و CSV | `data/extra.js` |
| **Symbol** (۷) | هر نماد: بازده کل و قیمت تعدیل‌شده در برابر «شاخص كل»، رویدادهای سود/افزایش سرمایه، مجامع کدال، تغییر تعداد سهام، مشخصات. با کلیک روی هر نماد در جدول‌ها یا `SYM فملی` | `data/symbols.js` (۶ مگابایت؛ فقط وقتی این نما باز شود بارگذاری می‌شود) |
| **Fund** (۸) | سبد هدف صندوق شاخصی (كل یا هم‌وزن) برای اندازهٔ دلخواه: مبلغ و تعداد سهم هر نماد، روز لازم برای ساخت با مشارکت محدود در حجم؛ CSV سفارش‌ها | `data/extra.js` |
| **Risk** (۹) | افت از اوج و نوسان ۶۳ روزهٔ سری‌های رسمی، جدول هر سال شمسی، همبستگی ماهانهٔ ۱۲ صنعت بزرگ | `data/extra.js` |

## ساخت داده
```
pip install pandas numpy
python tools/build_ui_data.py     # → ui/data/data.js   (Index Lab)
python tools/build_ui_extra.py    # → ui/data/extra.js  (نماهای ۲ تا ۶، ۸، ۹)
python tools/build_ui_symbols.py  # → ui/data/symbols.js (نمای ۷)
```
هر سه فایل در مخزن commit شده‌اند؛ برای دیدن وضعیت فعلی لازم نیست دوباره بسازید.

## کنترل‌ها
- دکمه‌های «كل / هم‌وزن» و «از ۲۰۱۴ / از ۲۰۱۶»، یا فرمان‌ها در نوار بالا (`/` یا `Ctrl+K`): `GO INDEX|DIV|FAC|REB|QA|REP|SYM|PF|RISK` · `SYM <نماد>` · `IDX K` · `IDX EW` · `WIN 2014` · `WIN 2016` · `THEME` · `DENSITY` · `HELP`؛ ↑/↓ در نوار فرمان = فرمان‌های قبلی
- نشانگر موس روی نمودارها: مقادیر همان روز. دکمهٔ CSV هر پنل: خروجی همان جدول.
- تم، تراکم (Compact/Comfortable) و آخرین نما در مرورگر ذخیره می‌شوند. زیر ۱۰۰۰ پیکسل چیدمان تک‌ستونی است.

## چه چیزی واقعی است
همهٔ اعداد از دادهٔ مخزن می‌آیند. «پیش‌نمایش پژوهشی» (Factor Lab) و «فرضی» (هزینهٔ معامله در Rebalance، تأخیر ثابت و نرخ وام در Dividend Lab) در خود صفحه برچسب دارند. پنل «داده تاریخ واقعی پرداخت» در Dividend Lab فقط شمار دادهٔ کدال را نشان می‌دهد؛ توزیع تأخیر واقعی ساخته نشده، چون پیوست‌های زمان‌بندی عمدتاً اسکن‌شده‌اند (`docs/10`، 7f). Fund مدل ساده است (بدون صف، دامنهٔ نوسان و هزینه).
