# UI — SIM Index Lab

صفحهٔ واقعی (نه نمایشی): همهٔ اعداد از دادهٔ مخزن می‌آیند.

## باز کردن
1. (فقط وقتی داده عوض شد) بسازید:
   ```
   pip install pandas numpy
   python tools/build_ui_data.py
   ```
   خروجی `ui/data/data.js` در مخزن commit شده است؛ پس برای دیدن وضعیت فعلی لازم نیست دوباره بسازید.
2. فایل `ui/index.html` را در مرورگر باز کنید (دوبار کلیک یا `start ui\index.html`). سرور لازم نیست.

python tools/analyze_fund_holdings.py                 # تجزیهٔ بازده فعال با پرتفو (پس از parser)

## کنترل‌ها
- دکمه‌های «كل / هم‌وزن» و «از ۲۰۱۴ / از ۲۰۱۶»، یا فرمان‌ها در نوار بالا (`/` یا `Ctrl+K`): `GO INDEX|DIV|FAC|REB|QA|REP|SYM|PF|RISK|FND` · `SYM <نماد>` · `IDX K` · `IDX EW` · `WIN 2014` · `WIN 2016` · `THEME` · `DENSITY` · `HELP`؛ ↑/↓ در نوار فرمان = فرمان‌های قبلی
- نشانگر موس روی نمودارها: مقادیر همان روز. دکمهٔ CSV هر پنل: خروجی همان جدول.
- تم، تراکم (Compact/Comfortable) و آخرین نما در مرورگر ذخیره می‌شوند. زیر ۱۰۰۰ پیکسل چیدمان تک‌ستونی است.

## راهنمای شناور
نشانگر را روی هر برچسب، ستون، شاخص، دکمه یا نشان نگه دارید تا تعریف، فرمول و مرجع سند نمایش داده شود. برچسب‌های دارای راهنما خط‌چین زیرشان دارند. واژه‌نامه: `ui/glossary.js`؛ موتور: `ui/tips.js`.

## داده و روش
همهٔ اعداد از دادهٔ مخزن محاسبه می‌شوند. ورودی‌ها (هزینهٔ رفت‌وبرگشت، تأخیر پرداخت سود، نرخ وام، مشارکت در حجم) پارامترهای صریح‌اند و نتیجه بلافاصله با آن‌ها دوباره محاسبه می‌شود. محدودیت‌های هر روش در پنل «روش و محدودیت‌ها» یا نوار منشأ همان نما آمده است. بازده‌ها با سال تقویمی سالانه می‌شوند (فصل ۷ §۷٫۳).

## نمودارها: زوم، ردگیری، برچسب روی محورها (`chartkit.js`)
همهٔ نمودارهای سری زمانی (Index Lab، Dividend Lab، Factor Lab، Symbol، Risk، Index Funds) از یک موتور رسم می‌شوند:
- **زوم:** چرخ موس (حول نشانگر)، کشیدن روی نمودار برای انتخاب بازه، دکمه‌های ＋ − ◀ ▶ ⟲ بالای نمودار؛ **Shift+کشیدن** یا Shift+چرخ: جابه‌جایی؛ دابل‌کلیک یا Esc: بازنشانی. در Index Funds زوم بازهٔ تحلیل را عوض می‌کند و همهٔ آمار از نو محاسبه می‌شود.
- **هوور/ردگیری:** خط‌چین عمودی و افقی، نقطه روی هر سری، **برچسب تاریخ (میلادی · شمسی) روی محور افقی، برچسب مقدار نشانگر روی محور راست، و برچسب مقدار هر سری روی لبهٔ چپ**، به‌علاوه جعبهٔ شناور با همهٔ مقدارها.
- **کیبورد:** با فوکوس روی نمودار، ← → نقطه‌به‌نقطه (Shift = ۱۰ نقطه)، + − زوم، Esc بازنشانی.
- محور عمودی روی بازهٔ دیده‌شده دوباره مقیاس می‌شود؛ برچسب‌های محور افقی با بازه عوض می‌شوند (سال، فصل، ماه، نیم‌ماه، روز شمسی). سری‌های بلند با کاهش نقطه (کمینه/بیشینهٔ هر پیکسل) رسم می‌شوند تا قله‌ها گم نشوند.
- میله‌ها (فصلی‌بودن، توزیع) با هوور مقدار و برچسب را نشان می‌دهند.
