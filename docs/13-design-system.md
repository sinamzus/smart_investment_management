# ۱۳ — دیزاین سیستم «Ledger» (SIM)

> **وضعیت:** نسخهٔ ۰.۲. فایل‌ها: `ui/tokens.css`، `ui/components.css`، و صفحهٔ **واقعی** `ui/index.html` (Index Lab) که از `ui/data/data.js` می‌خواند. این بسته را `tools/build_ui_data.py` از دادهٔ مخزن می‌سازد؛ هیچ عدد ساختگی‌ای در UI نیست. راهنمای اجرا: `ui/README.md`. نمونهٔ ساختگی قبلی (`ui/prototype/`) حذف شد.
> مبنا: بنچمارک فصل ۱۲ + اصول فصل ۱. اسکرین‌شات‌های این نسخه فقط با داده ساختگی گرفته شده‌اند و **فونت‌های Vazirmatn/JetBrains Mono در محیط من بارگذاری نشدند** (جایگزین سیستمی دیده شد)؛ ظاهر نهایی تایپوگرافی را روی سیستم خودتان بسنجید.

## ۱۳.۱ اصول طراحی

1. **ابزار، نه صفحهٔ بازاریابی.** مخاطب، تحلیل‌گر و مدیر سرمایه است که ساعت‌ها با آن کار می‌کند. چگالی و دقت بر فضای خالی مقدم است.
2. **هر عدد، منشأ دارد.** هر پنل نوار «Lineage» دارد: مبنای قیمت، نسخهٔ جهان، تاریخ داده، مدل هزینه، ارجاع به روش. این نقطهٔ تمایز اصلی ما با Bloomberg/FactSet است (فصل ۱۲، بند ۱۲.۳).
3. **فرمان‌محور، ماوس‌پذیر.** هر صفحه با نوار فرمان (`/` یا `Ctrl+K`) و کلید عددی قابل دسترسی است.
4. **ثبات رفتاری.** یک جدول همه‌جا یک‌جور رفتار می‌کند (مرتب‌سازی، انتخاب، CSV، پین ستون).
5. **رنگ معنا دارد، نه تزئین.** رنگ فقط برای: تعامل (accent)، جهت (سبز/قرمز)، وضعیت (هشدار/خطا/اطلاع)، گروه لینک. هر معنایی که با رنگ منتقل شود با نشانهٔ دوم (▲▼، علامت، حرف گروه) هم منتقل می‌شود.
6. **RTL-first.** ساختار از راست شروع می‌شود؛ ارقام و نمودار زمان همیشه چپ‌به‌راست.
7. **ساده پیش‌فرض، عمیق در دسترس** (لایه‌ای کردن پیچیدگی).

## ۱۳.۲ «خط قرمز»: چه چیزی نباید شبیه UI جنریک AI باشد؟

این فهرست، چک‌لیست بازبینی هر صفحهٔ جدید است. اگر هر مورد نقض شد، صفحه برگردانده می‌شود.

| ممنوع | چرا جنریک است | جایگزین ما |
|-------|----------------|------------|
| زمینهٔ کرم/بژ گرم، لحن «کاغذی» | امضای رایج UI‌های Claude/دستیارها | خاکستری-سرد/تیرهٔ سرد (`--bg-app` تا `--bg-head`) |
| عنوان‌های سریف و تایپوگرافی «ادیتوریال» | همان | Vazirmatn (UI) + JetBrains Mono (اعداد) |
| تراکوتا/نارنجی گرم به‌عنوان accent | همان | Cobalt `--accent` فقط برای تعامل |
| گرادیان بنفش-آبی، glow، glassmorphism | کلیشهٔ SaaS هوش مصنوعی | سطح تخت، خط ۱px، بدون سایه |
| کارت‌های بزرگ با گوشهٔ ۱۲–۲۴px و سایه نرم | کلیشه | گوشه ≤ ۲px، پنل با خط جداکننده، بدون سایه |
| فاصله‌گذاری سخاوتمندانه، تیتر ۲۴–۴۰px | داشبورد وب‌سایت‌گونه | ریتم ۴px، متن ۱۲–۱۳px، ردیف ۲۶px |
| دستیار چت به‌عنوان صفحهٔ اصلی | «محصول AI-first» کلیشه‌ای | نوار فرمان + پنل‌های داده؛ هوش مصنوعی فقط ابزار داخل پنل |
| KPIهای بزرگ با آیکن دایره‌ای رنگی | الگوی قالب‌های داشبورد | نوار KPI افقی چگال، بدون آیکن |
| نمودار پیش‌فرض کتابخانه (میلهٔ رنگارنگ، tooltip شناور بزرگ) | همان | سری‌های محدود، برچسب مستقیم، ruler تیک‌دار |
| ایموجی/آیکن‌های رنگی در رابط | همان | حرف/نماد تک‌رنگ |
| انیمیشن ورود/فید طولانی | تزئینی | حداکثر ۹۰–۱۴۰ms برای وضعیت‌ها |

**امضای بصری ما (آنچه UI را قابل‌شناسایی می‌کند):**
1. **نوار گروه لینک** (۳px رنگی + حرف A–F) در ابتدای سربرگ پنل.
2. **نوار Lineage** خط‌چین زیر هر پنل.
3. **خط‌کش تیک‌دار** محور زمان و خط‌های شبکهٔ هم‌فاصله در نمودارها.
4. **اعداد تک‌فاصله (monospace)** با ترازبندی جدولی.
5. **گوشه‌های تیز + خط ۱px** در همه‌جا؛ بدون سایه.
6. نشان «SIM» به‌صورت یک نشانهٔ پلکانی (پله‌های ledger) کنار نام.

> **ارزیابی صادقانه:** در این تکرار، ترکیب «تیرهٔ سرد + آبی کبالت» به‌تنهایی منحصربه‌فرد نیست؛ هویت از *ساختار* می‌آید (۱ تا ۶ بالا). اگر مایل باشید هویت رنگی جداگانه‌ای (مثلاً بر اساس هویت بصری نهاد) جایگزین cobalt شود، فقط `--accent*` عوض می‌شود.

## ۱۳.۳ توکن‌ها (خلاصه؛ مرجع: `ui/tokens.css`)

### رنگ (تیره — پیش‌فرض)
| توکن | مقدار | کاربرد |
|------|-------|--------|
| `--bg-app` | `#0A0E13` | زمینهٔ برنامه |
| `--bg-panel` | `#0F151C` | بدنهٔ پنل |
| `--bg-head` | `#141C25` | سربرگ پنل/ستون/نوار |
| `--bg-hover` / `--bg-select` | `#18222D` / `#1B2A44` | تعامل |
| `--line` / `--line-strong` | `#212C38` / `#31404F` | خط‌ها |
| `--tx-1/2/3` | `#E6EBF0 / #9AA7B4 / #6B7886` | متن اصلی/ثانویه/کم‌رنگ |
| `--accent` | `#5B8CFF` | فقط تعامل |
| `--up` / `--down` | `#2FC27B` / `#F0615F` | صعود/نزول (عرف بازار ایران: سبز = صعود) |
| `--warn` | `#E3B341` | هشدار |

حالت روشن (`data-theme="light"`) خاکستری سرد با پنل سفید است (نه کرم). **تضاد متن** باید به WCAG AA (۴٫۵:۱ برای متن معمولی) برسد؛ بررسی خودکار در گام بعد (کار باز ۱۳.۸).

### تایپوگرافی
- UI: `Vazirmatn` 12–13px؛ اعداد: `JetBrains Mono` با `tabular-nums` و `direction:ltr`.
- اندازه‌ها: 10.5 / 11.5 / 12 / 13 / 15 / 18px. بالاتر از ۱۸px فقط در گزارش چاپی.
- ارقام داده: لاتین (هم‌عرض، مطابق TSETMC)؛ ارقام فارسی فقط در متن توضیحی.
- **تاریخ‌ها:** شمسی در UI، میلادی در خروجی ماشینی؛ همیشه با رقم لاتین و `YYYY/MM/DD`.

### فاصله، شکل، چگالی
مبنا ۴px (`--s-1..6` = 2…24px). شعاع گوشه `2px`. ارتفاع ردیف: ۲۶ (compact، پیش‌فرض) / ۳۰ / ۳۶px.

### گروه‌های لینک
۶ گروه A–F با رنگ و **حرف**. تغییر نماد/شاخص/استراتژی در یک پنل، پنل‌های هم‌گروه را به‌روز می‌کند.

**ساخته‌شده در نسخهٔ ۰.۲:** نوار فرمان با پنج فرمان (`IDX K`، `IDX EW`، `WIN 2014/2016`، `THEME`، `HELP`)، کلیدهای میان‌بر (`/`، `Ctrl+K`)، نمودار با crosshair و خوانش مقدار، خروجی CSV هر پنل، نوار Lineage با مقادیر واقعی. صفحات Factor Lab / Rebalance / Reports / Data QA غیرفعال‌اند (برچسب «هنوز ساخته نشده»).

**هنوز نیست (به‌ترتیب اولویت):** History فرمان‌ها؛ مجازی‌سازی جدول (> ۱۰۰۰ ردیف)؛ ستون‌پین و تغییر عرض؛ ذخیرهٔ چیدمان؛ drill-down از هر عدد به Lineage؛ tooltip/crosshair نمودار؛ حالت‌های خالی/خطا/بارگذاری؛ تست a11y خودکار.

## ۱۳.۶ قواعد نمودار (جدول و نمودار پیش از تزئین)

- سری اصلی: روشن‌ترین (`--ch-1`)، مرجع: accent (`--ch-2`)، مرجع دوم: خاکستری فولادی خط‌چین (`--ch-3`). بیش از ۳–۴ سری هم‌زمان نه.
- خط‌های ۱–۱٫۶px، بدون پر کردن زیر منحنی، بدون سه‌بعدی، بدون محور دوم گمراه‌کننده.
- زیرپنل تفاوت (bp) همراه نمودار مقایسه؛ **مقیاس لگاریتمی** برای بازدهی تجمعی بلندمدت (اختیاری).
- محور زمان LTR حتی در صفحهٔ RTL.
- برچسب مستقیم/افسانهٔ کنار نمودار، نه tooltip بزرگ.
- هر نمودار خروجی CSV دارد و Lineage.

## ۱۳.۷ دسترس‌پذیری و بین‌المللی‌سازی

- فوکوس قابل‌مشاهده (`:focus-visible`)، قابل پیمایش با کیبورد، اندازهٔ هدف کلیک ≥ ۲۲px در چگالی compact.
- معنا هرگز فقط با رنگ؛ ▲▼ و علامت.
- RTL با ویژگی‌های منطقی CSS (`inline-start/end`) تا اگر نسخهٔ انگلیسی خواستیم، فقط `dir` عوض شود.
- `prefers-reduced-motion` (در تکرار بعد).
